# Simplified Technical English

Verified on 2026-11-04.

Write every rule, skill, spec, commit message, and PR description in Simplified Technical English. An agent reads these files on every run. A sentence with one meaning gives one result.

- One word, one meaning. Do not call the same thing a page, a screen, and a view.
- Use the active voice and a simple tense: "The check reports 3 actions", not "3 actions have been reported".
- One instruction per sentence. Start it with the verb.
- Keep the articles: "Run the formatter", not "run formatter".
- No idioms or metaphors. Say what happens: "the write replaces the file with no warning", not "silently clobbers".
- Count, do not estimate. Write "6 call sites", not "a handful".
- Put the evidence in the text: the release it was verified on, and the class or file that proves it.
